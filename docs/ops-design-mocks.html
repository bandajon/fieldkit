1xAssumptions & visual system (read first)
Carried from the node console

Machine data always mono + tabular. State is an 8 px dot beside neutral uppercase text — never a filled pill. Hit targets ≥ 48 px. State color (ok / warn / bad) is signal only, never decoration.

Distinct on purpose

Node console = dark charcoal. Ops console = light Industry ground with a solid steel HIVE OPS header band. One glance tells you which console you're on. Blueprint corner-marks frame hives and dialogs.

Assumed from the brief

Worst-first sort everywhere. Hierarchy: hive › node hostname › camera (site in details). Three bandwidth rungs: grid = 30–60 s snapshots · node focus = fast snapshots · camera focus = the single live sub-stream. Commands are desired state with per-node acks.
